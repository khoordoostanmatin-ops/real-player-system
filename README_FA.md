# REAL PLAYER SYSTEM — نسخه ۰.۱

یک وب‌اپلیکیشن قابل نصب (PWA) با رابط فارسی راست‌به‌چپ، تم آبی/تیره، مأموریت روزانه، XP، لِوِل‌آپ، رتبه، آمار قابل‌ویرایش و گزارش پیشرفت.

## اجرای سریع روی گوشی

برای نصب PWA، فایل‌ها باید از طریق HTTPS یا localhost باز شوند؛ بازکردن مستقیم `index.html` معمولاً قابلیت نصب و حالت آفلاین را فعال نمی‌کند.

### روش ساده با GitHub Pages (رایگان)
1. یک حساب GitHub بساز یا وارد حسابت شو.
2. یک repository جدید بساز.
3. فایل‌های داخل این پوشه را در ریشه repository بارگذاری کن.
4. در Settings → Pages، انتشار از شاخه `main` و پوشه `/(root)` را انتخاب کن.
5. پس از انتشار، نشانی سایت را در Chrome اندروید باز کن.
6. از منوی سه‌نقطه Chrome گزینه **Install app** یا **Add to Home screen** را بزن.

### اجرا روی کامپیوتر برای آزمایش
اگر Python نصب است، داخل همین پوشه اجرا کن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کن. برای نصب روی گوشی باید سایت روی HTTPS در دسترس باشد.

## ذخیره‌سازی و حریم خصوصی
- داده‌ها در `localStorage` مرورگر همان دستگاه ذخیره می‌شوند.
- حذف داده‌های مرورگر، پاک‌کردن اطلاعات سایت یا استفاده از مرورگر/دستگاه دیگر ممکن است پیشرفت را از بین ببرد.
- این نسخه حساب کاربری، همگام‌سازی ابری یا پشتیبان‌گیری خودکار ندارد.
- برای خروجی گرفتن/وارد کردن فایل پشتیبان در نسخه بعدی می‌توان قابلیت اضافه کرد.

## ویژگی‌های نسخه اولیه
- مأموریت‌های روزانه ثابت با XP
- تکمیل هر مأموریت فقط یک بار در روز
- لِوِل‌آپ با آستانه افزایشی XP
- رتبه نمایشی E تا S بر اساس سطح
- شش شاخص قابل ویرایش؛ تکمیل مأموریت‌ها بعضی شاخص‌ها را یک واحد بالا می‌برد
- نام بازیکن و گزارش رویدادهای اخیر
- ذخیره محلی و کش اولیه برای استفاده آفلاین پس از بارگذاری اول

## محدودیت‌های فعلی
- این پوشه یک PWA است، نه APK آماده. برای ساخت APK بومی باید مرحله بسته‌بندی اندروید (مثلاً با Capacitor و Android Studio یا یک سرویس build معتبر) جداگانه انجام شود.
- آمار و رتبه در این نسخه بازی‌وارسازی‌اند و معیار پزشکی یا ارزیابی رسمی رزمی نیستند.
- فونت از Google Fonts بارگیری می‌شود؛ در حالت آفلاین، اگر قبلاً کش نشده باشد ممکن است فونت جایگزین نمایش داده شود.
